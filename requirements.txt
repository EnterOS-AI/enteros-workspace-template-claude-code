# Molecule AI workspace runtime — shared infrastructure.
# The 0.4 floor includes the provider-neutral channel contract and the hardened
# declared-plugin installer. Earlier installers did not fail closed on dot-path
# install names, so this security floor must stay aligned with .runtime-version.
# The platform-agent / concierge also needs
# get_display_instructions (molecule_runtime/executor_helpers.py) + the
# config-driven extra-MCP support. Those symbols first ship in runtime 0.3.x;
# 0.2.x LACKS get_display_instructions, so an image built against a 0.2.x
# resolution crashes adapter.setup() with
# `ImportError: cannot import name 'get_display_instructions'` (-32603).
# The exact build pin is forwarded by publish-image.yml as the RUNTIME_VERSION
# build-arg sourced from .runtime-version; this floor is the
# defensive contract for any resolution that does NOT carry that override.
molecules-workspace-runtime>=0.4.0

# P0 band-aid for canvas-chat upload 400 "failed to parse multipart form"
# (task #256; forensic a5bb950f). Starlette `Request.form()` raises
# AssertionError parsing multipart bodies when python-multipart is absent.
# The runtime wheel carries this dependency transitively. Keep the direct floor
# as defense in depth for local tooling that reads this file without installing
# the runtime wheel first.
python-multipart>=0.0.27
